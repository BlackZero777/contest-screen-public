# 比賽快篩｜參賽工作台 V2

這是供公開網站使用的發布儲存庫，與私人開發儲存庫分開。

## 功能
- 簡章快篩：貼上競賽簡章，快速整理參賽資格、AI 規範、截止日期、費用、作品規格、評審方式與授權等待查項目。
- 貼文快篩：把社群貼文當成線索，仍須回到官方簡章核實。
- 找比賽線索：使用公開競賽資料快取，並嘗試向公開來源取得新資料。
- 依參賽偏好篩選：AI 圖像、數位設計、低投入文字、AI 音樂，以及「AI 單圖＋短動畫延伸」等方向。

## 重要提醒
- 自動搜尋只提供線索，不代表資料完整，也不取代官方簡章查核。
- 沒有查到 AI 規則、費用或截止日期，不代表允許 AI、免費或沒有期限。
- 本工作台不會代替使用者報名、投稿或公開參賽作品。
- 瀏覽器貼上的簡章文字由前端規則處理；仍請避免貼入密碼、身分證字號等敏感資料。
- 本儲存庫的公開程式碼與資料會被任何人讀取。

## 自動更新
GitHub Actions 每日執行公開競賽資料同步，並先做 JavaScript 語法檢查及篩選規則回歸測試。
