# 比賽快篩｜我的參賽工作台 V3

公開網站僅包含執行所需的前端檔案。開發來源仍為原始私人儲存庫 `BlackZero777/contest-screen` 的 `feature/v3-workbench` 分支。

## 功能
- 簡章與社群貼文快篩
- 比賽線索探索
- 個人參賽規則與競賽紀錄
- 待研究清單、研究交接提示詞與研究結果回填
- JSON 匯出／匯入備份

## 個人資料保存
競賽紀錄儲存在目前瀏覽器的 localStorage（`contest-screen-v3-records-v1`），不會自動跨裝置同步。請定期使用工作台的 JSON 匯出功能備份；更換瀏覽器或裝置時再匯入。

請勿將個人紀錄、私人文件或雲端存取憑證提交到公開儲存庫。
